# AnalyticalTable Plugin: useAnnounceEmptyCells

<ImportStatement moduleName={'useAnnounceEmptyCells'} packageName={'@ui5/webcomponents-react/AnalyticalTableHooks'} />

The `useAnnounceEmptyCells` plugin hook adds screen reader announcements for empty cells.

**Note:** Some screen readers (depending on their configuration) automatically detect empty cells, potentially resulting in duplicate announcements of empty cells.

**Disabling:** Call it as a factory with `disabled: true` (`useAnnounceEmptyCells({ disabled: true })`) to turn the hook off while keeping it in `tableHooks`. See [Disabling a Plugin Hook](?path=/docs/data-display-analyticaltable-plugin-hooks--docs#disabling-a-plugin-hook).

## Example

<Canvas sourceState="none" of={ComponentStories.PluginAnnounceEmptyCells} />

```jsx
const tableHooks = [useAnnounceEmptyCells] // this array should be memoized

<AnalyticalTable
  data={data}
  columns={columns}
  visibleRows={5}
  tableHooks={tableHooks}
/>
```

**First data entry with empty values or undefined fields:**

```js
{
  age: undefined,
  friend: {
    name: '',
    age: 0
  },
  status: 'Error'
}
```
