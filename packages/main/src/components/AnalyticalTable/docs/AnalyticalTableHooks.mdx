# Plugin Hooks

<ImportStatement moduleName={'* as AnalyticalTableHooks'} packageName={'@ui5/webcomponents-react/AnalyticalTableHooks'} defaultImport />

We're offering plugin hooks to extend the functionality of the `AnalyticalTable` component. The following hooks are available:

- [useAnnounceEmptyCells](?path=/docs/data-display-analyticaltable-plugin-hooks-useannounceemptycells--docs)
- [useF2CellEdit](?path=/docs/data-display-analyticaltable-plugin-hooks-usef2celledit--docs)
- [useIndeterminateRowSelection](?path=/docs/data-display-analyticaltable-plugin-hooks-useindeterminaterowselection--docs)
- [useManualRowSelect](?path=/docs/data-display-analyticaltable-plugin-hooks-usemanualrowselect--docs)
- [useOnColumnResize](?path=/docs/data-display-analyticaltable-plugin-hooks-useoncolumnresize--docs)
- [useOrderedMultiSort](?path=/docs/data-display-analyticaltable-plugin-hooks-useorderedmultisort--docs)
- [useRowDisableSelection](?path=/docs/data-display-analyticaltable-plugin-hooks-userowdisableselection--docs)
- [useStickyColumns](?path=/docs/data-display-analyticaltable-plugin-hooks-usestickycolumns--docs)

## Add a Plugin Hook to the AnalyticalTable

Import the hooks from the `@ui5/webcomponents-react/AnalyticalTableHooks` package and incorporate them into your `AnalyticalTable` component by adding them to the `tableHooks` array.

**Example:**

```jsx
import {useAnnounceEmptyCells} from '@ui5/webcomponents-react/AnalyticalTableHooks';

const tableHooks = [useAnnounceEmptyCells]; // this array should be memoized

//...

<AnalyticalTable {...otherProps} tableHooks={tableHooks} />
```

## Disabling a Plugin Hook

Every plugin hook accepts a `disabled` option (default `false`). When `disabled` is `true`, the hook keeps its slot in the `tableHooks` array but does nothing.

React's [rules of hooks](https://react.dev/reference/rules/rules-of-hooks) forbid adding or removing `tableHooks` entries at runtime, so use `disabled` to switch a hook off instead. To toggle it while the table is mounted, re-create the hook **at the same position** in the (memoized) `tableHooks` array with the new `disabled` value — never add, remove, or reorder entries, and keep `disabled` in the array's dependencies.

The two hooks that are usually passed by reference (`useAnnounceEmptyCells`, `useF2CellEdit`) also accept the option when called as a factory. The call form depends on the hook's other parameters:

```jsx
const tableHooks = useMemo(
  () => [
    useAnnounceEmptyCells({ disabled }), // factory form of a by-reference hook
    useStickyColumns({ disabled }), // options object
    useManualRowSelect('isSelected', { disabled }), // positional arg + options
  ],
  [disabled],
);

<AnalyticalTable {...otherProps} tableHooks={tableHooks} />;
```
